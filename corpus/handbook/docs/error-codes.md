# Error Codes

Error codes appear on the display when the appliance detects a fault. Switch the appliance off at the socket for 60 seconds before anything else, because this clears most temporary faults.

## Dishwasher codes
- E15: water has been detected in the base of the dishwasher. Turn off the water supply and contact support. Do not keep using the dishwasher.
- E22: the filter is blocked. Clean the filter and restart the programme.
- E24: the dishwasher cannot drain. Check the drain hose for kinks and check the waste pipe connection.
- E09: heating element fault. This needs a technician visit.

## Washing machine codes
- F05: the machine cannot drain within 6 minutes. Clean the drain pump filter behind the flap at the bottom right.
- F08: the water is not heating. This needs a technician visit.
- F13: the door lock has failed to engage. Close the door firmly and check that no clothing is trapped in the seal.
- F21: too much foam. Let the machine finish, then run a rinse cycle and use less detergent next time.

## Refrigerator codes
- H1: the fresh food compartment has been too warm for more than 3 hours. Check the door and avoid opening it until the code clears.
- H4: the freezer sensor has failed. Food stays frozen, but book a technician visit.
- dF: a defrost cycle is running. This is normal and clears by itself within 40 minutes.

## If a code keeps coming back
Write down the code and the programme that was running, and contact support. A code that returns three times within one week normally points to a failed part.
